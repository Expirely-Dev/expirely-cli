---
title: Install
description: Install expirely with Go.
---

expirely is one static binary. It needs Go 1.27 or newer to build:

```sh
go install github.com/bycavii/expirely-cli/cmd/expirely@latest
expirely --version
```

`go install` puts the binary in `$(go env GOPATH)/bin`; add that directory to your `PATH` if `expirely` is not found.

To install a specific version, replace `latest` with a tag such as `v0.1.0`.
