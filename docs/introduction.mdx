---
title: Introduction
description: Find every TLS certificate you serve and when it expires.
---

expirely connects to each target you give it, completes a TLS handshake, reads the certificate chain and closes the connection. It tells you which certificates are expired, which expire soon and which targets could not be read, in a short list for people and in JSON for CI and AI agents.

It sends no application data, holds no credentials and never touches a private key. Expired, untrusted and mismatched chains are read and reported, not refused.

<Note>
  expirely is in early development. Until 1.0, a release can change flags, JSON fields and codes; the [changelog](https://github.com/expirely-dev/expirely-cli/blob/main/CHANGELOG.md) says what changed and what to do.
</Note>

```
$ expirely tls example.com expired.badssl.com wrong.host.badssl.com localhost:1 self-signed.badssl.com untrusted-root.badssl.com

  expired  expired.badssl.com         4,246 days ago      Apr 12 2015
  failed   localhost:1                connection refused
  ok       wrong.host.badssl.com      31 days             Dec 28 2026  wrong name
  ok       example.com                88 days             Feb 22 2027
  ok       self-signed.badssl.com     727 days            Nov 23 2028  self-signed
  ok       untrusted-root.badssl.com  727 days            Nov 23 2028  untrusted issuer

  1 expired, 1 failed, 4 ok in 622ms
```
