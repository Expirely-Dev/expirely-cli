## Exit codes

When a scan has several outcomes, 1 wins over 3.

| Code | Meaning |
|---|---|
| 0 | Every target is `ok`, or `--help` or `--version` ran |
| 1 | At least one certificate is `expired` or `expiring` |
| 2 | Usage error: bad flag, invalid target, unreadable `--file` or no targets |
| 3 | At least one target could not be read, or writing the output failed |

## Error codes

Scripts and agents match on `code`; a code is never renamed or reused. Each error also carries a `remediation`, shown on the line after the message in text, saying what resolves it. When an AI agent is detected, a usage error (exit `2`) also carries `usage`, the whole help. A command error is one JSON line on stderr when output is JSON:

```json
{"error":{"code":"invalid_flag","message":"unknown flag --nope","remediation":"expirely --help lists every flag and the values it accepts."}}
```

| Code | Exit | Meaning |
|---|---|---|
| `invalid_flag` | 2 | A flag is unknown or has a bad value |
| `invalid_target` | 2 | A target is not a host, host:port or https:// URL |
| `missing_arguments` | 2 | No target was given in the arguments or files |
| `file_unreadable` | 2 | A `--file` could not be opened or read, or has a line over 64 KiB |
| `invalid_ca_file` | 2 | A `--ca-file` could not be read, holds no PEM certificate, or holds one that does not parse |
| `aws_not_configured` | 2 | `expirely aws` found no region, or the profile does not exist in the shared AWS config |
| `aws_access_denied` | 3 | AWS refused the credentials, they expired, or they lack the ACM read permissions |
| `aws_request_failed` | 3 | Another AWS failure, such as a timeout or a throttled request |
| `gcp_not_configured` | 2 | `expirely gcp` found no project, or no Application Default Credentials |
| `gcp_access_denied` | 3 | Google Cloud refused the credentials, or they lack the Compute list permissions |
| `gcp_compute_disabled` | 3 | The project has the Compute Engine API or billing disabled, so it serves no Compute SSL certificates |
| `gcp_request_failed` | 3 | Another Google Cloud failure, such as a timeout or a server error |
| `output_failed` | 3 | Writing the result to stdout failed, for example a closed pipe |

A target that could not be read is a result, not a command error: its `status` is `error` and its `error.code` is one of these.

| Code | Exit | Meaning |
|---|---|---|
| `dial_failed` | 3 | The TCP connection to the target failed |
| `handshake_failed` | 3 | The TLS handshake failed or the server sent no certificate |
