---
title: Quickstart
description: Scan your first targets and read the result in a minute.
---

<Steps>
  <Step title="Install">
    ```sh
    go install github.com/expirely-dev/expirely-cli/cmd/expirely@latest
    ```
  </Step>
  <Step title="Scan a host">
    ```sh
    expirely tls example.com
    ```

    Each line is one target: its status (`ok`, `expiring`, `expired` or `failed`; the cloud commands and `--revocation` add `unknown` and `revoked`), the whole days left until the first certificate in the chain expires, the date it expires and, when the chain is not trusted, why, such as `self-signed` or `wrong name`. A target that could not be read shows the reason instead, such as `connection refused`.
  </Step>
  <Step title="Scan a list">
    Put one target per line in a file; blank lines and lines starting with `#` are skipped:

    ```text targets.txt
    # production
    example.com
    api.example.com:8443
    ```

    ```sh
    expirely tls -f targets.txt --warn-days 21
    ```
  </Step>
  <Step title="Act on the exit code">
    ```sh
    expirely tls -f targets.txt || echo "a certificate needs attention"
    ```

    The exit code is `1` when a certificate is expired or expires within `--warn-days`, and `3` when a target could not be read or an end date is unknown. [Gate CI and alert from cron](/cli/guides/ci) builds on it.
  </Step>
</Steps>
